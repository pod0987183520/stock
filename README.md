# 小股同學 - 防失智長者股票認知訓練與資產關懷 PWA Web App

專為「防失智 / 輕度失智長者」量身打造的極簡股票認知訓練與家庭資產關懷單一應用程式（All-in-One PWA）。長輩與晚輩安裝同一套 App，結合高對比無障礙設計、語音互動助理「小股」、日常認知問答與溫情陪伴建議，讓長者在無壓力的互動中鍛鍊記憶、維持對生活的參與感與安心感。

## 🎯 核心產品特點

1. **單一 App 雙角色極致便利 (All-in-One)**：長輩與晚輩安裝同一套 App，省去分開發布與下載的麻煩。
2. **連續點擊 10 下防誤觸解鎖 (10-Click Unlock)**：取代容易誤觸的長按機制，確保長輩日常絕不誤入後台。
3. **手機號碼極簡綁定**：晚輩直接輸入長輩手機號碼建立永久關聯，免密碼、免簡訊驗證。
4. **靈活適應三大族群**：家庭晚輩陪伴模式、虛擬模擬大亨模式、獨立長者營業員模式。
5. **夜間沉睡與日落安撫**：下午收盤或夜間自動進入睡眠模式，化解半夜找股票的焦慮。
6. **擬人化語音助手「小股」**：支援語音模糊關鍵字識別、溫柔容錯台階與慢速自然朗讀。
7. **專家委員會嚴格品質閘門**：所有程式碼必須通過架構師、QA、UI 師、UX 師與長照醫學顧問層層把關。
