## 🏆 方法一：Google 試算表 API 結合前端擬真跳動 (當前採用實作)

### 1. 設計哲學與優勢
- **極致零維護**：不依賴任何易失效的第三方網頁爬蟲，由 Google 官方伺服器與交易所介接行情。
- **100% 規避反爬與 CORS**：Google Apps Script (GAS) Web App 原生支援 CORS，絕無驗證碼 (CAPTCHA) 或 IP 封鎖風險。
- **符合台股升降法規**：前端嚴格遵循台灣證券交易所（TWSE）官方 6 大價格升降單位（Tick Size）進行 ±2 單位自然跳動，搭配紅漲綠跌閃爍，提供長輩最真實的看盤沉浸感與防失智大腦刺激。

### 2. 階段一：Google 端建置步驟 (5 分鐘完成)

#### 步驟 1：建立 Google 試算表
1. 開啟 [Google 雲端硬碟](https://drive.google.com/)，新增一個 Google 試算表（命名為 `小股同學_股票行情庫`）。
2. 在試算表工作表 `Sheet1` 中建立以下格式：
   - `A1`: 股票代號（例如 `2330`、`2317`、`2412`、`0050`、`6547`）
   - `B1`: 股票名稱（例如 `台積電`、`鴻海`、`中華電`）
   - `C1`: 填入 Google Finance 公式：`=GOOGLEFINANCE("TPE:" & A1, "price")`（上櫃請用 `"TWO:" & A1`）
   - `D1`: 昨收價公式：`=GOOGLEFINANCE("TPE:" & A1, "closeyest")`

#### 步驟 2：建立 Apps Script Web API
1. 點擊試算表頂部選單【擴充功能】➔【Apps Script】。
2. 將編輯器內的原有代碼替換為以下程式碼：

```javascript
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var result = {};
  
  // 遍歷試算表所有列 (從第 1 列開始)
  for (var i = 0; i < data.length; i++) {
    var code = data[i][0] ? data[i][0].toString().trim() : '';
    if (code) {
      var name = data[i][1] ? data[i][1].toString().trim() : '';
      var price = parseFloat(data[i][2]) || 0;
      var prevClose = parseFloat(data[i][3]) || price;
      
      result[code] = {
        id: code,
        name: name,
        price: price,
        prevClose: prevClose,
        updatedAt: new Date().toISOString()
      };
    }
  }
  
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}
```

#### 步驟 3：發布為 Web 應用程式 (Web App)
1. 點擊右上角【部署】➔【新增部署作業】。
2. 齒輪圖示選擇【網頁應用程式】。
3. 設定：
   - 說明：`小股同學股票行情 API`
   - 執行身分：**我 (您的 Google 帳號)**
   - 誰可以存取：**所有人 (Anyone)** *(重要！)*
4. 點擊【部署】，複製生成的 **網頁應用程式網址**（格式為 `https://script.google.com/macros/s/XXXXX/exec`）。

### 3. 階段二：前端 App 串接與台股升降級距邏輯

#### 1. 台股官方 6 階升降單位規範 (Tick Size Engine)
```javascript
function getTaiwanTickSize(price) {
  if (price < 10) return 0.01;
  if (price < 50) return 0.05;
  if (price < 100) return 0.1;
  if (price < 500) return 0.5;
  if (price < 1000) return 1.0;
  return 5.0; // 1000 元以上每跳 5 元 (如台積電)
}
```

#### 2. 雙週期心跳架構
- **長週期（每 15 分鐘）**：發送 HTTP GET 至 GAS API 網址，更新基準價格（Anchor Base Price）與昨日收盤價。
- **短週期（每 15 秒）**：隨機產生 `-2 ~ +2` 個 Tick 單位，與基準價格相加產生顯示現價，並觸發「變大 ＋ 紅色/綠色閃爍動畫」。

## 🥈 方法二：富邦新一代 API (Fubon Neo API / WebSocket 轉發)

### 1. 適用場景與特色
- **毫秒級即時撮合**：盤中每一筆真實委託、撮合成交價秒級推播。
- **合規官方通道**：由富邦證券與 Fugle 富果團隊合作開發之現代化 REST/WebSocket API。
- **架構需求**：需常駐運行一台後端伺服器（Node.js / Python）掛載下單數位憑證（`.pfx`），負責與富邦主機建立 WebSocket，再轉發至手機前端。

### 2. 行政申請手續 (100% 線上辦理，免臨櫃)
1. **申請數位交易憑證**：
   - 電腦下載富邦證券官方「憑證 e 總管 (TCEM.exe)」。
   - 登入身分證字號與網頁密碼，點選「申請憑證」，產出 `C:\CAFubon\身分證字號.pfx` 檔案並記住憑證密碼。
2. **簽署 API 風險聲明書**：
   - 登入 [富邦新一代 API 官網](https://www.fbs.com.tw/TradeAPI/) 簽署「API 交易風險預告書」。
3. **完成連線測試**：
   - 下載官方「連線測試小幫手」，完成帳號連線測試即正式啟用。

### 3. 後端轉發伺服器範例 (Node.js + WebSocket Server)

```javascript
// server.js (需在有 Node.js 環境的伺服器執行)
const { FubonSDK } = require('fubon-neo-api');
const WebSocket = require('ws');

const sdk = new FubonSDK();
const wss = new WebSocket.Server({ port: 8080 });

async function initFubon() {
  // 1. 憑證登入
  await sdk.login({
    id: process.env.FUBON_USER_ID,
    pwd: process.env.FUBON_PASSWORD,
    certPath: './cert.pfx',
    certPwd: process.env.FUBON_CERT_PASSWORD
  });
  console.log('✅ 富邦 API 憑證登入成功');

  // 2. 訂閱台積電 (2330) 與 鴻海 (2317) 即時行情
  const ws = sdk.marketdata.websocket();
  ws.on('message', (data) => {
    const quote = JSON.parse(data);
    // 廣播給所有連線的手機前端 App
    wss.clients.forEach(client => {
      if (client.readyState === WebSocket.OPEN) {
        client.send(JSON.stringify({
          id: quote.symbol,
          price: quote.price,
          time: quote.time
        }));
      }
    });
  });
  ws.subscribe(['2330', '2317']);
}

initFubon();
```

## 🥉 方法三：官方合法開放資料源 (TWSE / FinMind 備援)

- **資料端點**：
  - 臺灣證券交易所 OpenAPI：`https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL`
  - 櫃買中心 TPEx OpenAPI：`https://www.tpex.org.tw/openapi/v1/tpex_mainboard_daily_close_quotes`
  - FinMind 官方開放介面：`https://api.finmindtrade.com/api/v4/data?dataset=TaiwanStockPrice`
- **特點**：
  - 每日 13:30 收盤後由官方產出當日結算行情。
  - 當【方法一】或【方法二】未設定時，作為系統的自動保底字典庫。
