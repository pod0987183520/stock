# 01. 系統架構與功能規劃

## 一、 產品定位與核心精神
- **產品定位**：專為防失智、輕度失智長者設計的「股票認知訓練 + 情感陪伴 + 家庭資產關懷」單一 Web App (All-in-One PWA)。
- **單一 App 理念**：長輩與晚輩安裝**同一個 App**，免去分開下載的繁瑣。透過「裝置角色切換」，一套程式碼滿足雙端需求。

---

## 三、 三大適用情境模式

1. **家庭晚輩陪伴模式 (Family Care)**：
   - 長輩手機設為「長輩模式」；晚輩手機設為「晚輩模式」並綁定長輩手機號碼。
   - 股票微幅拉回時，晚輩一鍵送紅包，創造電話互動契機。
2. **模擬大亨陪伴模式 (Simulation Tycoon)**：
   - 預設 100 萬虛擬資金，享受持股樂趣，零真實金錢壓力。
3. **獨立長者 / 營業員模式 (Self-Trader)**：
   - 獨居或具獨立操作能力的長輩，作為大字體看板，達標一鍵撥打給營業員。

---

## 四、 長者主畫面 (Senior View)

1. **頂部狀態與小股語音**：
   - 個人化時段問候：「{User_Title}，早安！」搭配小股說話光暈動效。
2. **股票卡片 (最多 3 檔)**：
   - 巨大現價、原始買價、現有股數。
   - 雙重文字標籤（【賺 $12,500 元】/【少 $3,000 元】），搭配邊緣柔和呼吸燈（Glow Pulse）。
   - 目標價超大 `[ ＋ ]` 與 `[ － ]` 微調按鈕。
   - 達標一鍵撥號大按鈕 `[ 📞 撥打給小明（兒子） ]` 或 `[ 📞 撥打給營業員 ]`。
3. **每日認知問答卡片 (Daily Brain Check)**：
   - 題型包含「賺賠直覺二選一」、「買價記憶」與「產業常識」。
   - 支援 Web Speech 語音回答與超大卡片點擊雙軌機制。
4. **夜間沉睡與休市安撫 (Sundowning Care)**：
   - 13:30 收盤後或 21:00～09:00 自動進入靜謐星空模式，安撫長輩半夜找股票的焦慮。
5. **孝親紅包彈窗**：
   - 收到晚輩紅包時跳出喜慶紅包動畫，點擊收下存入虛擬口袋。

---

## 五、 晚輩控制台 (Caregiver Panel)

- **解鎖方式**：右上角 Logo / 小圖示**連續快速點擊 10 下**（長輩完全不會誤觸）。
- **功能列表**：
  1. 裝置角色切換（長輩模式 vs 晚輩模式）。
  2. 長輩手機號碼綁定（免簡訊驗證碼）。
  3. 長輩稱謂（伯伯/阿姨/姓名）與聯絡電話設定。
  4. 股票清單與配股股數調整。
  5. 遠端發送孝親紅包 / 虛擬股息。
  6. Email 定期關懷提醒設定。
