# 02. 長者無障礙 UI/UX 設計規範

為確保失智症、輕度認知障礙與高齡長者（Senior-friendly）能以極致零負擔的心態使用，本 App 在視覺、動效、觸覺與聽覺上嚴格遵循 WCAG 2.1 AAA 標準。

---

## 一、 字級與排版規範 (Typography & Layout)

1. **基礎字級階梯**：
   - **全站最小內文字體**：$24\text{px}$ ($1.5\text{rem}$)。
   - **輔助說明 / 狀態文字**：$28\text{px} \sim 32\text{px}$。
   - **問候語與卡片標題**：$32\text{px} \sim 36\text{px}$。
   - **巨大數字（股價 / 損益金額）**：$44\text{px} \sim 60\text{px}$（超大粗體，即使視力退化也能一眼辨識）。
2. **零摩擦力版面配置**：
   - 保持單一長卷軸或卡片化佈局，無複雜分頁標籤（Tabs）或抽屜式導覽（Drawer），長者一目了然。

---

## 二、 柔和光感與色彩對比 (Color & Subtle Glow)

```
┌─────────────────────────────────────────────────────────────┐
│                 色彩與光效設計規範                          │
├───────────────────┬─────────────────────────────────────────┤
│ 日間護眼底色       │ 沉穩藍灰深色底 (#0B1329) 或 米白底 (#F8FAFC) │
│ 主要文字           │ 高對比淨白 (#FFFFFF) 或 深海藍 (#0F172A)    │
│ 獲利/增值呼吸燈    │ 溫潤翡翠綠光暈 (Box-shadow Glow Pulse)       │
│ 虧損/拉回呼吸燈    │ 暖陽琥珀金光暈 (柔和不刺眼，避免警告紅)      │
│ 夜間沉睡模式底色   │ 星空幽藍 (#050B14) + 暖月黃微光              │
└───────────────────┴─────────────────────────────────────────┘
```

> 🌟 **動效升級要點**：
> 全面採用**「柔和卡片邊緣呼吸燈 (Glow Pulse)」**，光暈週期約 $3 \sim 4\text{s}$，既有生命感又保護長者視力。

---

## 三、 長者專屬觸控與防手震防誤觸機制 (Ergonomics)

1. **超大觸控熱區**：
   - 所有主要按鈕高度 $\ge 68\text{px}$，寬度佔螢幕 $85\%$ 以上。
   - 目標價加減按鈕 `[ ＋ ]` 與 `[ － ]` 採用 $72\text{px} \times 72\text{px}$ 超大圓角方形，兩鍵水平間距 $\ge 28\text{px}$，預防手指微顫誤觸。
2. **防手震防抖過濾 (Debounce $300\text{ms}$)**：
   - 連續點擊時自動限流，避免數字瞬間暴衝造成長者驚慌。
3. **晚輩後台「連續點擊 10 下」防誤觸解鎖 (10-Click Unlock)**：
   - 取代容易被長者不自覺長按誤觸的長按機制。
   - 在右上角 Logo / 小圖示上，需在 $4$ 秒內**連續快速點擊 10 下**才能進入晚輩設定後台。
   - 第 7、8、9、10 下給予極輕微的點擊震動或隱藏計數回饋，長者在日常生活中絕對不會誤觸進入。

---

## 四、 激勵動效與情感關懷反饋 (Reinforcement)

1. **問答答對（金牌成就）**：
   - 螢幕中心彈出立體「神算金牌」徽章，伴隨金幣清脆鈴聲與慢速彩帶，持續 2.5 秒。
2. **收到晚輩紅包（孝親紅包動效）**：
   - 畫面中央浮現喜慶典雅的大紅包，輕輕晃動並伴隨溫暖語音，點擊「收下紅包」直接存入累積零用金。
3. **夜間沉睡切換動效**：
   - 畫面平滑淡入星月夜景，時鐘以超大字體顯示「21:30 休息時間」，背景伴隨大自然蟲鳴白噪音（可選開關）。
