# 05. 專家決策小組與品質驗收規範 (Quality Gate Protocol)

為確保「小股同學」在失智照護醫學、長者人因工程 (Senior Ergonomics)、無障礙視覺美學、雙端資料聯動與 PWA 系統工程上達到最高品質標準，特成立「產品決策與驗收委員會」，並制定雙階段嚴格驗收與打回機制。

  │ 第一階段：系統架構與功能邏輯閘門 (Stage 1) │ ──(未通過)──► 【打回工程修復】

## 三、 驗收清單核對表 (Checklist)

### 閘門 1：架構與功能技術檢驗 (AGY 架構師 + QA 測試師)
- [ ] **純前端 PWA**：無外部依賴、純 HTML/CSS/JS 即可秒開。
- [ ] **離線可用性**：Service Worker 離線快取完備，斷網時核心功能 100% 正常。
- [ ] **防誤觸判定**：連續快速點擊 10 下精準觸發（超時或未達次數立即重置）。
- [ ] **資料持久化**：LocalStorage 讀寫無誤，長輩手機號碼綁定與持股數據精確計算。

### 閘門 2：三師專業終審檢驗
1. **UI 視覺總監**：
   - [ ] 螢幕全站文字 $\ge 24\text{px}$，主要股價與損益文字 $\ge 44\text{px}$。
   - [ ] 獲利與拉回採用柔和呼吸燈（Glow Pulse），絕無視覺刺眼劇烈閃爍。
   - [ ] 損益標籤必備中文文字【賺 $XXX 元】/【少 $XXX 元】。
2. **UX 體驗架構師**：
   - [ ] 目標價加減按鈕具備 $300\text{ms}$ 防手震防抖機制。
   - [ ] 語音辨識具備模糊關鍵字比對與 6 秒未答自動溫柔給台階。
   - [ ] 晚輩端發送孝親紅包時，長輩端同步彈窗且不露餡。
3. **長照醫學顧問**：
   - [ ] 問答題型設計溫和，答錯無刺耳警報或紅色叉叉。
   - [ ] 停損語意完全包裝為「保護資產、安心睡眠」。
   - [ ] 收盤與夜間自動啟動日落安撫模式，播放舒緩心靈口語。
